## 7. BASE DE DATOS MYSQL (Servicio separado en Easypanel)

### Crear servicio MySQL:
- Nombre del servicio: `mysql_service`
- Imagen: `mysql:8.0`
- Puerto interno: `3306`

### Variables de entorno para MySQL:
```
MYSQL_ROOT_PASSWORD=Cusiana2026Inventario!Seguro
MYSQL_DATABASE=inventario
MYSQL_USER=inventario_user
MYSQL_PASSWORD=Cusiana2026Inventario!Seguro
```

### Volumen para persistencia:
- Mount path: `/var/lib/mysql`
- Volume name: `mysql_data`

### Importar base de datos inicial:
Después de crear el servicio MySQL, importar el archivo `inventario.sql`:
```bash
# Copiar el archivo al contenedor
docker cp inventario.sql <container_id>:/tmp/inventario.sql

# Importar
docker exec -i <container_id> mysql -u inventario_user -p inventario < /tmp/inventario.sql
```

## 8. PASOS DE DEPLOYMENT

1. **Crear servicio MySQL primero** con la configuración anterior
2. **Esperar a que MySQL esté healthy** (1-2 minutos)
3. **Crear la aplicación Flask** con las variables de entorno
4. **Asegurarse que INVENTARIO_DB_HOST apunta a `mysql_service`**
5. **Importar la base de datos** usando el archivo inventario.sql
6. **Configurar el dominio** en Easypanel
7. **Probar el login** con admin@cusiana.edu.co / AdminCusiana2026!

## 9. TROUBLESHOOTING

Si la app no arranca:
- Verificar logs del contenedor Flask
- Verificar que MySQL esté corriendo y accesible
- Verificar que las variables de entorno estén correctamente configuradas
- Verificar que INVENTARIO_DB_HOST sea el nombre correcto del servicio MySQL

Si hay error de conexión a base de datos:
- Verificar que ambos servicios estén en la misma red
- Verificar credenciales de MySQL
- Ejecutar: `docker logs <flask_container_id>` para ver errores específicos
